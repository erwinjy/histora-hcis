# 史鉴

**面向严谨历史研究的证据、因果与世界重建系统**

## 这是什么

史鉴不是一个“替你讲历史故事”的问答工具，而是一套把**原始史料、来源批判、主张、证据、事实判断、研究假说与因果分析**连接起来的研究系统。

它的核心目标是让任何重要结论都可以沿着证据链回到原始材料，并且把“知道”“推断”“争议”“缺失”明确区分开。

> **先有证据，再有结论；先保留不确定性，再谈解释。**

---

## 为什么做史鉴

传统历史研究中的困难往往不是“没有文本”，而是：

- 同一事件散落在不同史书、奏疏、地方志、档案和数据集中；
- 史料之间存在抄袭、转引、版本差异和来源依赖；
- “文献记载”不等于“客观事实”；
- 人口、军队、财政、灾害、粮价等数字常常口径不同；
- 研究者容易把观察、解释和因果判断混在一起；
- 复杂历史问题需要跨越政治、经济、人口、环境、技术、交通、组织和心理等多个维度。

史鉴把这些问题变成可以追踪、核验和复算的研究对象。

## 核心研究链

```mermaid
flowchart LR
    A[原始史料与数据] --> B[不可变原件库]
    B --> C[文字解析与识别]
    C --> D[来源批判]
    D --> E[实体、时间与地点解析]
    E --> F[事件候选]
    F --> G[主张]
    G --> H[证据]
    H --> I[事实判断]
    I --> J[研究假说]
    J --> K[因果分析]
    K --> L[历史世界重建]

    H --> M[冲突与来源依赖]
    G --> M
    I --> N[不确定性与缺失状态]
```

史鉴不会把这些层级压成一个“答案”。

```text
原始史料
→ 史料中的主张
→ 观察
→ 事实判断
→ 解释
→ 因果判断
→ 行为与心理解释
→ 受约束的反事实
```

## 关键原则

| 原则 | 含义 |
|---|---|
| 证据优先 | 重要结论必须能够回到来源与原始字节 |
| 不确定性优先 | 无法确认时明确保留争议、可能、未知或缺失 |
| 观察不等于解释 | 记录到的现象与研究者的解释分层保存 |
| 来源独立性很重要 | 多份互相抄录的材料不能被当成多份独立证据 |
| 当时语境优先 | 优先恢复历史参与者当时能知道什么、如何理解 |
| 没有证据不等于证伪 | 缺失、未记载、材料散佚与不可观察必须区分 |
| 模拟必须校准 | 任何重建与反事实都必须受到真实证据约束 |

## 历史世界模型

史鉴把历史研究拆成若干相互关联的世界层，并在同一个工作区中保持它们之间的边界。

```mermaid
flowchart TB
    S[来源世界] --> O[观察世界]
    O --> R[客观世界]
    O --> U[主观世界]
    U --> C[社会世界]
    R --> C
    C --> K[因果世界]
    K --> F[反事实世界]

    P[人口] --- K
    E[环境] --- K
    Z[资源] --- K
    T[技术与知识] --- K
    I[基础设施] --- K
    M[经济] --- K
    D[分配] --- K
    N[制度] --- K
    G[组织] --- K
    Q[信息] --- K
    L[文化与正当性] --- K
    A[安全与战争] --- K
```

其中技术、能源、材料、基础设施、人口、劳动力和迁移不是附属标签，而是历史世界中的一级驱动维度。

## 当前已经能做什么

### 一、建立真实史料库

- 导入文本、表格、扫描件与图像；
- 为原件计算摘要并保存来源信息；
- 原件进入后不可被后续识别结果覆盖；
- 派生数据可以重建，原始材料保持不变。

### 二、从史料建立可回证的研究对象

- 实体、别名、时间、地点与事件；
- 主张、证据、事实候选与冲突组；
- 来源关系与文本异文；
- 观察数据与代理指标；
- 研究问题与竞争性假说。

### 三、从结论回到原始材料

当前发布版已经实测贯通：

```mermaid
flowchart LR
    A[事实候选] --> B[证据]
    B --> C[主张]
    C --> D[来源位置]
    D --> E[来源版本]
    E --> F[原始文件字节]
```

在有精确区域坐标时可以做区域级定位；没有精确区域坐标时只显示真实存在的页码、区块或字符区间，不会估算一个看似精确的位置。

### 四、研究问题与知识图

- 以研究问题为作用域加载知识图；
- 展示真实关系，不生成虚构的历史关系；
- 事实、证据、主张和来源可以互相跳转；
- 覆盖度与冲突状态可以在研究工作区中查看。

### 五、受控资料获取

系统已经具备资料获取工作流的基础能力：

```mermaid
flowchart LR
    Q[研究问题] --> G[证据缺口]
    G --> P[检索规划]
    P --> C[候选来源]
    C --> R[权限与来源判断]
    R --> A[允许获取的材料]
    A --> V[原件库]
    V --> E[主张与证据]
```

它适合接入公开图书馆、档案馆、研究机构和开放数据来源。对于登录、付费、验证码、版权或其他访问限制，系统应明确标记阻断状态，而不是伪装成“已获取”。

它**不是一个可以绕过网站限制的通用网络爬取器**。

## 代码锁

史鉴把核心领域契约视为受保护层。

受保护内容包括领域模型、核心枚举、适配器契约、资料获取契约、接口契约、模式定义和验收测试等。

任何需要改变核心语义的修改都必须先提交契约变更提案，说明：

1. 为什么现有契约不能满足需求；
2. 哪些受保护文件会变化；
3. 数据迁移方案；
4. 向后兼容方案；
5. 测试方案；
6. 回滚方案。

这样做的目的，是防止实现代理为了“方便开发”而悄悄改变历史研究的认识论边界。

## 已知边界

当前发布版明确**没有**声称以下能力已经完成：

### 桌面包不含完整扫描识别运行时

开发环境可以具备扫描识别能力，但封板桌面包没有打入完整识别和图像处理资源；桌面实例会诚实显示资源缺失，而不是显示可用。

### 历史地名没有可靠几何时不画点

当前真实库中的地名不自动获得坐标。没有可信历史地理数据时，系统只保留文本地名和来源，不会让模型猜一个位置。

### 物理全新电脑验证尚未测量

已经完成隔离环境模拟和目录外启动，但没有把“开发机上的干净环境”冒充成“全新物理电脑”。

### 高阶研究层仍在后续版本

更完整的因果识别、反事实、认知与决策层、高级研究运行对比、历史世界模型和更深的覆盖来源追踪仍在后续版本继续推进。

详见：

- `histora-instrument/KNOWN_LIMITATIONS_RC0.md`
- `histora-instrument/RC1_BACKLOG.md`
- `histora-instrument/RC1_BACKLOG_ADDENDA.md`

## 适合谁

史鉴面向需要处理复杂史料与长期证据链的研究者和个人研究项目，尤其适合：

- 历史学与历史社会科学研究；
- 多来源史料交叉核验；
- 长时段因果问题；
- 历史气候、人口、财政、战争和技术研究；
- 需要让人工智能输出能够回到原始证据的研究流程。
